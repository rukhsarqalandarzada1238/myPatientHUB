# MyPatientHUB

Welcome to **MyPatientHUB** — a smart healthcare platform designed to bring healthcare services to your hands.

## 🚀 Features
- Responsive login page with sign-in and sign-up options
- Social login buttons (Facebook, Google)
- Dashboard with navigation
- Mobile-friendly design

## 📂 Project Structure
- `hub.html` → Login page
- `dashboard.html` → Dashboard page
- `hub.css` → Stylesheet
- `hub.js` → JavaScript functionality
- `image/` → Project images

## 🛠️ Technologies Used

- CSS3
- JavaScript
- Font Awesome icons
